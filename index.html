推荐用法（3 步）

为什么方式一（验证码登录）不成功？
后台任务跑在海外服务器，中国移动对该类出口做了安全拦截（报错常为 ec=S001 / 风控），验证码能发出但登录会被拦。这是运营商风控，换登录次数通常无效； 请优先用「方式二 粘贴 authorization」，签到 / 续期不受影响。

抓到的令牌在哪？
账号授权信息在本机浏览器中加密保存，并可加密同步到 GitHub 仓库供 Actions 使用。

粘贴 authorization（自动识别）

把抓包复制的内容整体粘贴进来即可——单行、整段请求头、Authorization: Basic …、JSON、cURL 都行。点「识别并添加」自动解析。

如何获取 authorization（图文教程）

不需要抓包工具，用支持 Chrome 扩展的浏览器装一个小扩展，一键就能导出。推荐浏览器：Kiwi Browser（安卓手机）、Microsoft Edge / Google Chrome（电脑）。

电脑 Chrome / Edge：打开下方官方商店链接，点「添加至浏览器」即可。手机端请用 Kiwi Browser（安卓，支持扩展），同样从商店安装。

⏳ 做任务前先看这个（重要）

云朵不会立刻到账，这是正常机制，不是失败：
① 延迟多久：任务完成后，云朵一般要等 24 小时内（次日） 才会变成可领取的气泡。
② 月度奖励更久：带「月」标的任务，奖励要到 次月 1 号 才可领，面板会显示为「下月 X 豆」。
③ 刚做完就去领 → 显示 0：这是正常的，因为气泡还没生成。请不要急着反复点「领气泡」，更别以为脚本坏了。
④ 推荐节奏：今天执行任务，明天再点「刷新全部云朵状态」或「领气泡」，就能领到了。
每天 09:05 的定时任务会自动做任务 + 领气泡，其实不用手动点。
